Trust HBOX on this device

HBOX uses its own certificate. Install it once on each phone, tablet and computer: browsers stop warning, and apps such as Immich and Nextcloud can connect.

Download the profile
  1. Open this page in Safari and tap the button above, then Allow.
  2. Open Settings, tap Profile Downloaded at the top (or General → VPN & Device Management → HBOX) and tap Install.
  3. Go to Settings → General → About → Certificate Trust Settings and turn on HBOX Local Certificate Authority. Apps stay untrusted until this is on.
Download the certificate
  1. Open Settings → Security → More security settings → Encryption & credentials → Install a certificate → CA certificate (the names vary a little by phone).
  2. Tap Install anyway and pick hbox-ca.crt from Downloads.
Download the certificate
  1. Open hbox-ca.crt from Downloads; Keychain Access adds it to the login keychain.
  2. Double-click HBOX Local Certificate Authority, open Trust and set When using this certificate to Always Trust.
  3. Quit and reopen the browser.
Download the certificate
  1. Open hbox-ca.crt and click Install Certificate.
  2. Choose Local Machine, then Place all certificates in the following store → Trusted Root Certification Authorities.
  3. Restart the browser. (Firefox: Settings → Privacy & Security → Certificates → Import, too.)
Download the certificate
  1. Run sudo cp hbox-ca.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates.
  2. Browsers with their own store (Firefox, Chrome): import it in their certificate settings.

Install the update

HBOX backs up first, then updates. Apps may be unavailable for a few minutes.

Sign in with the HBOX administrator account (sudo hbox credentials).
